# Third-party components

Live Companion includes the Vosk speech-recognition library and the `vosk-model-small-en-us-0.15` English model by Alpha Cephei, distributed under the Apache License 2.0. See https://alphacephei.com/vosk/models and https://github.com/alphacep/vosk-api.

The Windows package includes the Python embeddable distribution, SoundCard, NumPy, CFFI, Vosk and their Python dependencies. The Linux package includes Vosk and its Python dependencies. License files for the embedded Python distribution and installed Python packages are included with their respective distributions.
